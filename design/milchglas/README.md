# Design Milchglas (TET, seit 28.10.2026)

Übergabe für den Umbau des Mentee-Portals, Stand 13.11.2026. Nur Material, nichts davon ist eingebunden.

- `tet-logo-hell.svg`: Wortmarke hell (Pearl), 148 × 30 px in der Kopfzeile
- `tet-zeichen-hell.svg`: Bildzeichen, unter 375 px Breite statt der Wortmarke
- `manrope.ttf` + `OFL.txt`: einzige Schrift, variabel 200–800, selbst gehostet (SIL Open Font License)
- `milchglas.css`: Stilblatt des Socialmediastudios als Vorlage. Die Klassennamen gehören dem Studio; übernehmen sollen Tokens (`--mg-*`), Grund mit Licht, Glas, Knöpfe, Handy- und Transparenz-Regeln. Pfade zu Schrift/Logo dort zeigen auf `./milchglas/`.
- `beschreibung-aus-studio.md`: Beschreibung samt Rollen-Tabelle aus dem Studio

Dieser Branch wird nicht live gestellt. GitHub Pages baut nur aus `main`.
